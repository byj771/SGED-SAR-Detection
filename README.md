# SGED: Segmentation Guidance and Enhanced Diffusion for SAR Ship Detection

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20519224.svg)](https://doi.org/10.5281/zenodo.20519224)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Official PyTorch implementation of the paper **"[A Two-Stage Framework for SAR Near-Shore Ship Detection via Segmentation Guidance and Enhanced Diffusion]"**. 

This repository provides the code and dataset access guidelines for the Segmentation Guidance and Enhanced Diffusion (SGED) framework, designed for robust shore-sea segmentation and near-shore SAR ship detection.

## 📊 Dataset Availability

The self-built dataset used in this research is permanently hosted on Zenodo. Due to data protection guidelines, the dataset is available from the author upon reasonable request for academic research purposes.

**Access Link:** 
👉 **[YGA1-SSDD Dataset on Zenodo](https://zenodo.org/records/20519224)** (DOI: 10.5281/zenodo.20519224)

**How to get access:**
1. Click the Zenodo link above.
2. Scroll down to the `Files` section and click the **`Request access`** button.
3. Briefly state your name, affiliation, and the purpose of your research in the request form.
4. Once approved, you will be able to download the complete data files.
